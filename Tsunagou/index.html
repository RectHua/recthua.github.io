关于 Tsunagou

v0.1.0 Alpha

Tsunagou 是一个多 Agent 协作调度系统，旨在通过文档交换、契约更新、权限管理等调度机制，解决多个 Agent 在同一项目上共同协作时产生的冲突，使他们能够“看见彼此”、像人类一样协作，从而提升效率。

前端:陈林榕；后端:骆宣卓；测试:张子宸
